# پایش ویندوز و همگام‌سازی امن

## آنچه در شاخه feature/payesh-windows-sync اضافه شده
- پروژه دسکتاپ مستقل WPF برای Windows 10/11 x64 با رابط فارسی و فایل نصب‌کننده Inno Setup؛ نسخه فعلی ویندوز عمدتاً نمایشگر امن داده همگام‌شده است، نه انتقال کامل امکانات موبایل.
- ساخت آیکون اختصاصی ترازو و حرف T در گردش CI و ایجاد میانبر دسکتاپ.
- فضای کاری محلی رمزگذاری‌شده با AES-256-GCM و کلید مشتق‌شده با PBKDF2-HMAC-SHA256 (۶۰۰٬۰۰۰ دور).
- API همگام‌سازی با توکن مجزای هر کاربر، ذخیره payload رمزگذاری‌شده، نسخه‌گذاری خوش‌بینانه و پاسخ تعارض 409.
- گردش CI برای ساخت نصاب ویندوز و آزمون اولیه API.

## محدودیت‌های صریح
- این نخستین پوسته دسکتاپ است، نه انتقال کامل همه قابلیت‌های اندروید. ثنا، OCR، مدیریت کامل پرونده‌ها و رابط بومی اندروید هنوز در ویندوز پیاده نشده‌اند.
- کلاینت اندروید هنوز به API جدید متصل نشده است؛ بنابراین همگام‌سازی واقعی بین گوشی و ویندوز هنوز قابل استفاده نیست.
- سرویس باید روی میزبان دائمی با HTTPS معتبر مستقر و توکن‌ها از محیط امن پیکربندی شوند. این مخزن به‌تنهایی سرویس را میزبانی نمی‌کند.
- عبارت رمزگذاری باید در هر دو دستگاه یکسان و جدا از توکن دسترسی باشد. سرور متن فضای کاری را رمزگشایی نمی‌کند.
- تعارض‌ها خودکار ادغام نمی‌شوند. تا تکمیل آزمون‌های بازیابی، چرخش توکن، محدودسازی نرخ و بازبینی امنیتی، داده پرونده واقعی را به سرویس آزمایشی نفرستید.

## قرارداد نسخه اول
- GET /v1/sync/workspace: پاسخ JSON دارای revision و payload Base64.
- PUT /v1/sync/workspace: ورودی expectedRevision و payload؛ در صورت تغییر هم‌زمان پاسخ 409.
- هدر Authorization: Bearer <token> و X-Payesh-User: <userId>.
- payload، خروجی رمزگذاری‌شده کلاینت است و باید با بسته PAYESHE1 آغاز شود.
