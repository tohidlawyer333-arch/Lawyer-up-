# اعتبارسنجی فنی

این گزارش مربوط به سورس LawyerUp نسخهٔ ۲.۰.۰ و محیط محلی ویندوز در **۲۰ اکتبر ۲۰۲۶** است. آزمون‌ها تضمین نبود مطلق خطا، پوشش کامل قالب‌های حساب واقعی ثنا یا تأیید حقوقی محصول نیستند.

## اجراشده

- `:app:testDebugUnitTest`: موفق؛ آزمون‌های نرمال‌سازی، استخراج، صفحه‌بندی، تطبیق، مواعد، پشتیبان رمزدار، مخزن Room و تاریخ شمسی.
- `:app:lintDebug`: موفق؛ خطای lint باقی نماند.
- `:app:assembleDebug`: موفق؛ APK debug ساخته شد.
- `:app:assembleDebugAndroidTest`: موفق؛ APK آزمون رابط ساخته شد.
- `:app:assembleRelease`: موفق؛ خروجی release بدون امضای انتشار ساخته شد.
- `tests/web` با `npm test`: موفق؛ ۱۲ آزمون ساختار DOM مصنوعی، بدون کلیک روی دکمهٔ مشاهده یا ارسال.
- `connectedDebugAndroidTest`: موفق؛ هر ۳ آزمون رابط روی شبیه‌ساز `Pixel_API36` با API 36 گذشت.

## روش بیلد

بیلد محلی با Gradle Wrapper و JDK 17 انجام شد. برای محدودیت شبکهٔ این رایانه از mirror محلی Gradle استفاده شد؛ این mirror داخل سورس یا workflowهای GitHub قرار نگرفته است. workflowهای GitHub از مخازن استاندارد استفاده می‌کنند.

## خارج از دامنهٔ آزمون محلی

- ورود به حساب واقعی، OTP، CAPTCHA، دریافت کامل کارتابل شخصی و آزمون همهٔ قالب‌های سامانه انجام نشده است.
- کلید انتشار واقعی در محیط وجود نداشت؛ release حاصل unsigned است و باید در GitHub با secrets خودتان امضا شود.

## تفسیر نتیجهٔ همگام‌سازی

برنامه فقط دادهٔ قابل‌مشاهدهٔ فهرست فعلی را ذخیره می‌کند. صفحه‌بندی ناشناخته، نشست منقضی، قاب مسدود، ردیف بدون شناسه یا پاسخ غیر PDF موفقیت اعلام نمی‌کند. «بررسی کردم»، پیش‌نویس و مشاهدهٔ ابلاغیه، اقدام ثبت‌شده در سامانه محسوب نمی‌شوند.
