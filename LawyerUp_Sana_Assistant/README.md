# LawyerUp Sana Assistant

دستیار محلی و فارسی مدیریت کارهای حقوقی با Kotlin، Jetpack Compose، Room و WorkManager. پروژه برای Android Studio، JDK 17، Gradle 8.7، AGP 8.5 و SDK 34 تنظیم شده است.

## قابلیت‌ها
- مدیریت محلی پرونده‌ها، ابلاغ‌های قابل ثبت دستی، مواعد و پیش‌نویس‌ها
- محاسبه‌گر مستقل موعد: شمارش از روز بعد از تاریخ محرک، بدون تقویم تعطیلات hard-coded؛ تاریخ سررسید دستی قابل ویرایش است.
- اشتراک‌گذاری متن پیش‌نویس و بازکردن پرتال در مرورگر خارجی
- اعلان‌های محلی با کانال اعلان و درخواست امن مجوز Android 13+
- مرجع حقوقی موجود پروژه LawyerUp حفظ شده است.

## حریم خصوصی و ثنا
داده‌ها روی دستگاه و در دیتابیس محلی ذخیره می‌شوند و تحلیل‌گر، آپلود ابری یا گزارش‌گیری ندارد. برنامه لاگین خودکار، نگهداری رمز یا OTP، scraping، دورزدن CAPTCHA، ارسال خودکار، یا درخواست پنهان به ثنا/عدل ایران ندارد. تعامل پرتال فقط با اقدام آشکار کاربر در مرورگر خارجی انجام می‌شود.

## هشدار حقوقی
مواعد نمونه و محاسبات تقویمی، مشاوره حقوقی یا محاسبه قطعی مهلت نیستند. تعطیلات، مقررات خاص دادگاه، روش ابلاغ و قانون جاری باید توسط وکیل کنترل شود. ابلاغ و سند می‌تواند به‌صورت دستی ثبت شود؛ OCR فارسی ادعا نمی‌شود.

## بررسی
تست‌های واحد محاسبه موعد و اعتبارسنجی در `app/src/test` قرار دارند. در محیط تولید ZIP، Android SDK/کش وابستگی‌ها در دسترس این تولیدکننده نبود؛ بنابراین build نهایی در این محیط ادعا نشده است.


## ساخت و استفاده
در Android Studio نسخه جدید، پوشه پروژه را باز کنید، Gradle Sync را انجام دهید و از منوی Build گزینه Build APK را اجرا کنید. CI در GitHub Actions با JDK 17 و Gradle 8.7 تست واحد و assembleDebug را اجرا می‌کند. این خروجی Wrapper binary ندارد؛ بنابراین CI از Gradle نصب‌شده توسط action استفاده می‌کند.

## دامنه MVP
ثبت دستی پرونده، ابلاغیه، موعد و پیش‌نویس در Room انجام می‌شود. `ReminderWorker` کانال اعلان محلی را فراهم می‌کند و اتصال خودکار به ثنا ندارد. سیاست `AttachmentPolicy` فقط اعتبارسنجی اولیه نام/حجم/پسوند است و تبدیل فایل یا پذیرش ثنا را تضمین نمی‌کند. `CmsPhraseInterpreter` توضیح احتمالی و پیشنهاد بررسی می‌دهد و تحلیل حقوقی قطعی نیست. قواعد Jalali در رابط با برچسب فارسی قابل ثبت‌اند، اما هسته محاسبه تاریخ برای جلوگیری از ادعای دقت حقوقی از تاریخ ISO میلادی استفاده می‌کند.

هیچ رمز، OTP، کوکی یا داده‌ای به سرور ارسال نمی‌شود. بازکردن پرتال با مرورگر دستگاه و اقدام آشکار کاربر انجام می‌شود؛ ورود، CAPTCHA، scraping، دانلود خودکار، ارسال لایحه و امضای الکترونیکی عمداً پیاده‌سازی نشده‌اند. همه موعدها باید با متن ابلاغ، تقویم رسمی و وکیل مسئول کنترل شوند.
