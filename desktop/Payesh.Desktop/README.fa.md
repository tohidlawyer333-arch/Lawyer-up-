# پایش برای ویندوز — نسخه اولیه

این پروژه یک برنامه مستقل WPF برای Windows 10/11 (x64) است. فضای کاری محلی با AES-256-GCM رمزگذاری می‌شود و رابط فارسی/راست‌به‌چپ دارد.

## وضعیت این مرحله
- برنامه دسکتاپ مستقل و فایل نصب‌کننده در گردش CI ساخته می‌شوند.
- فضای کاری محلی رمزگذاری‌شده است.
- رمزگذاری سمت کاربر برای payload همگام‌سازی طراحی شده است؛ عبارت رمزگذاری به سرور ارسال نمی‌شود.
- **همگام‌سازی بین موبایل و ویندوز هنوز فعال/آماده استفاده نیست** تا سرویس مرکزی امن مستقر شود و کلاینت اندروید به همین قرارداد متصل شود.
- این پوسته هنوز تمام امکانات اندروید (پرونده‌ها، ابلاغ ثنا، OCR و پیگیری‌ها) را بازتولید نمی‌کند.

## حفاظت
- فقط HTTPS برای سرور راه دور پذیرفته می‌شود؛ HTTP فقط برای localhost در آزمون.
- کلید رمزگذاری با PBKDF2-HMAC-SHA256 و ۶۰۰٬۰۰۰ دور مشتق و با AES-256-GCM استفاده می‌شود.
- رمزگذاری مستقل از توکن دسترسی است. از عبارت رمزگذاری طولانی و منحصربه‌فرد استفاده کنید.
- تعارض محتوا به‌صورت خودکار ادغام نمی‌شود؛ برنامه از بازنویسی خاموش جلوگیری می‌کند.
- این MVP هنوز ممیزی امنیتی مستقل نشده و برای پرونده واقعی تا تکمیل احراز هویت سرور، کنترل تعارض و آزمون بازیابی مناسب انتشار عملیاتی نیست.

## ساخت محلی
نیازمند .NET 8 SDK و Windows است:
dotnet publish desktop/Payesh.Desktop/Payesh.Desktop.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
